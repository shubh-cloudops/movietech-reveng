# Iron Man (2008): scene notes template

Fill one block per scene where a software system does something. Skip action and drama scenes.
Save your finished notes as `C:\movietech\input\ironman_notes.md`. The pipeline reads this exact format.
Keep these notes private: don't commit them to the public repo.

Rules:
- Write what you **see and hear**, not how you think it works. The agents do the inferring.
- Use timestamps from your player (HH:MM:SS).
- Copy any on-screen text (HUD readouts, labels, percentages) exactly.
- Aim for 15 to 30 scenes. Short is fine.

---

## Scene N
- **Time:** 00:00:00 - 00:00:00
- **System:** (your name for it, e.g. JARVIS, suit HUD, workshop display)
- **What happens:** (1 to 3 sentences on what the character does and what the system does in response)
- **Input the system got:** (voice / gesture / touch / sensor / none visible)
- **Output the system gave:** (speech / display / movement / alert)
- **On-screen text:** "..."
- **Dialogue with the system:** "..."
- **Anything notable:** (speed, works in the dark, fails, multiple users, offline...)

---

## Example (made up, to show the level of detail)
- **Time:** 01:02:10 - 01:02:45
- **System:** Workshop display
- **What happens:** He spreads his hands and a 3D model of a part expands into exploded pieces. He flicks one piece into a bin and it disappears from the model.

- **On-screen text:** "COMPONENT REMOVED"
- **Dialogue with the system:** none
